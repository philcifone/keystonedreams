# keystonedreams

minimalist photography website hand made to showcase a personal project based on the state of pennsylvania

written in vanilla HTML and CSS, no javascript, no dependencies

SSI (server side includes) handled by nginx webserver

simply put:
```bash
    #Enable SSI
    ssi on;
```
in /etc/nginx/sites-available/website-conf

download .woff/2 Libre Baskerville files from fontsource github or pick your own from wherever and replace in styles.css

create images folder and update paths in photos.html with correct path/filenames
